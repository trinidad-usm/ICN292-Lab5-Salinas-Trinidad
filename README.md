## Cómo reproducir

1. Abrir MySQL Workbench conectado a un servidor MySQL 8.
2. Abrir el archivo `.sql` (File → Open SQL Script...).
3. Ejecutarlo completo con el primer rayo. El script parte con `DROP DATABASE IF EXISTS andesbike;`, así que recrea la base desde cero y se puede correr varias veces.
4. Las consultas 1 a 10 se ejecutan sobre la carga oficial y ninguna modifica los datos, así que se pueden correr en cualquier orden.
